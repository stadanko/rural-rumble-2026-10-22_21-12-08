# Reference Image Inbox

Drop new reference images and GIFs here (PNG, JPG, GIF).

Name each file after what it shows, e.g. `lockup-collar-elbow.gif`,
`recovering-clutch-ribs.png`, `trailer-porch-night.jpg`. If speed matters,
say so in the name (`-halfspeed`, `-fullspeed`).

When asked to process the inbox, Claude will:
1. Move each file to `docs/images/` using the next `style-guide-NN` number.
2. Link it under the matching section of `docs/STYLE_GUIDE.md`
   (e.g. Sprite Sheet & Animation Examples) with any notes you give.
3. Leave this README in place so the folder stays tracked.

These are reference examples only, never game assets. Nothing here
goes into `Assets/` or `docs/ASSET_REGISTRY.csv`.
