Xbox Style Controller Layout
- Left Stick/D-Pad = Move Player
    - Stick Up = Player moves up
    - Stick Up/Left = Player moves up/left
    - Stick Left = Player moves left
    - Stick Down/Left = Player moves down/left
    - Stick Down = Player moves down
    - Stick Down/Right = Player moves down/right
    - Stick Right = Player moves right
    - Stick Up/Right = Player moves up/right
- A Button = Lock Up/Grapple
    - If close to standing opponent & not in Lock Up animation
        - Trigger’s a Lock Up
    - If in Player Triggered Lock Up animation
        - Grapple 1
- B Button = Run/Whip
    - If not in Lock Up animation
        - Run in direction player is facing
    - If in Player Triggered Lock Up animation
        - If Left Stick/D-Pad is pressed
            - Whip opponent in direction Left Stick/D-Pad is pressed
        - Else
            - Whip opponent in direction opponent is currently facing
- X Button = Strike
    - If not in Lock Up animation
        - X pressed once = Strike 1
        - X pressed a second time within combo time window of first press = Strike 2
        - X pressed a third time within combo time window of second press = Strike 3
Xbox Controller to Keyboard Mapping
- Left Stick/D-Pad = WASD
- A Button = Left Shift
- B Button = Space Bar
- X Button = Right Shift
